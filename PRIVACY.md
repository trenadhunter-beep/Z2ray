# Privacy Policy

Z2ray is designed as a local Android VPN/Xray client.

## Data stored locally

The app stores the following on the device:

- Imported proxy configuration links and parsed server fields
- Subscription URLs and refresh metadata
- Local connection logs generated by the app
- User preferences such as theme, language, routing mode, and per-app proxy choices

## Network requests

The app may make network requests for:

- Refreshing user-provided subscription URLs
- Downloading `geoip.dat` and `geosite.dat` routing assets
- Optional connectivity/speed tests triggered by the user
- Connecting to the selected proxy server through Android VPN service

## No analytics by default

The app should not include third-party analytics, advertising SDKs, or telemetry by default. If any future build adds analytics, this file must be updated and the feature must be opt-in.

## Sensitive data

Proxy links may contain credentials. Treat exports, screenshots, logs, and QR codes as sensitive.
